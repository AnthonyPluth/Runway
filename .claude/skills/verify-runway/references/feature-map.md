# User feature map

Generated by `tools/user_feature_map.py` (`make user-feature-map`); do not edit. The gotchas come from [feature-gotchas.md](feature-gotchas.md), which is hand-edited. `make fleet-checks` fails when this file is out of date.

What a person can do in the web app, by page: what is there, how to reach it, how to drive it with `tools/control` (or `make verify`), and what usually breaks. It is not `docs/feature-map.json` (and its docs page), which goes by API route to find the code behind a feature; this goes by what a user does, from the pages and flows `make verify` runs. All of it is demo data; `tools/control start` first, and `flow <name>` runs a flow's steps (after `reset` for the data `make verify` starts it from).

## Transactions (`transactions`)

- **What exists:** The transaction list, review, categories, rules, splits and receipts. Docs: [Transactions](/Runway/using/transactions/).
- **Reach it:** desktop: sidebar > Day to day > Transactions; phone: the tab bar; URL `#transactions`; control `tools/control goto transactions`.
